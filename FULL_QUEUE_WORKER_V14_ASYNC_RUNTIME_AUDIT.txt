ROOT CAUSE
------------------------------------------------------------

ORIGINAL ERROR:
  RuntimeError: V14 is running inside Jupyter/Colab. Use: await main()

CAUSE:
  When the V14 source was executed inside a Google Colab cell the
  module-level `if __name__ == "__main__": run_worker()` triggered.
  `run_worker()` detected the IPython event loop via
  `is_running_in_notebook()` and raised RuntimeError.

  This was intentionally defensive but wrong: it should SCHEDULE
  main() on the existing loop, not refuse to start.

SECONDARY CAUSE:
  `RuntimeWarning: coroutine 'main' was never awaited` — this fires
  when a coroutine object is created (e.g. main()) without being
  awaited or scheduled. The broken run_worker() raised before scheduling
  so the main() object leaked as an un-awaited coroutine.

FUNCTIONS CHANGED
------------------------------------------------------------

1. run_worker()
   OLD: detected notebook -> raised RuntimeError
   NEW: REMOVED. Replaced by start_in_current_environment()

2. is_running_in_notebook()
   OLD: used only by run_worker() to raise
   NEW: kept as utility helper; checks ZMQInteractiveShell/
        TerminalInteractiveShell/InteractiveShell type names
        for accurate notebook detection

3. start_in_current_environment()  [NEW]
   - Checks asyncio.get_running_loop()
   - If loop running (Colab/Jupyter):
       loop.create_task(main()) -> stores in worker_main_task
       done-callback logs crash/cancel/complete
   - If no loop (terminal):
       asyncio.run(main())  (blocking)
   - Double-start guard: if _worker_started and task not done, logs
     [WARN] and returns existing task

4. run_worker_terminal()  [NEW]
   - Thin wrapper: asyncio.run(main())
   - Used for terminal execution fallback

5. Module-level auto-exec block  [NEW]
   - if __name__ != "__main__" and not _worker_started:
       checks get_running_loop()
       if running (exec() inside Colab cell): calls
       start_in_current_environment()
   - This is what makes exec(open("...").read()) work inside Colab

6. Globals: worker_main_task, _worker_started  [NEW]
   - worker_main_task: holds the asyncio.Task reference
   - _worker_started: bool double-start guard

7. main()
   - Added structured startup log sequence per blueprint:

   - Added outer try/except to set _worker_started=False on crash
